# Cotizador Miel & Sal

Sitio estático listo para GitHub Pages. Para publicarlo, sube el contenido de esta carpeta a un repositorio de GitHub y, en **Settings → Pages**, elige desplegar desde la rama principal y la carpeta raíz.

El precio se calcula por persona con mínimo de 50 invitados. El flete se confirma por WhatsApp y el servicio nocturno de $500 se agrega cuando el evento inicia a partir de las 8:00 pm.
